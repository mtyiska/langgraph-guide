# Product Roadmap — Project Atlas

## Phase 1 — January to June 2024

January: Project kickoff, architecture decisions, environment setup.
February: Data ingestion pipeline development begins. SAP connector design.
March: Core API development. PostgreSQL schema finalised (31 tables, 8 junction tables).
April: API development 60% complete. CI/CD pipeline operational.
May: API development complete. Integration testing begins.
June: Phase 1 complete. All 24 endpoints passing tests. Handoff to Phase 2.

## Phase 2 — July to November 2024

July: Dashboard component library development begins. Design system delivered.
August: Beta launch on August 15 2024 with 20 pilot users from finance team.
September: Dashboard 60% complete. UAT feedback incorporated.
October: UAT with 20 pilot users beginning October 15. Salesforce connector complete.
November: Full launch November 1 2024. All 200 target users onboarded.

## Post-Launch — December 2024 onwards

December: Stabilisation period. Support ticket volume monitoring.
Q1 2025: Self-serve analytics module development begins based on user feedback.
